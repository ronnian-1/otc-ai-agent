# 作品展示：有来源边界的导购原型

这是一个基于Python 3.10、LangChain 1.x、本地JSON和规则审核的作品集。两条商品及两条评论均为此公开版独立编写的虚构内容，未接入真实天猫、旺旺、商家账号、真实评论或订单。

## 可以审查的实现

- `app/agent/agent.py`：完整轮次编排、名称解析、任务工具校验与最终审核。
- `state.py` / `memory.py` / `facts.py`：显式选择与条件、聊天历史、工具事实及来源版本，职责分别可查。
- `execution.py`：预算与同步等待边界；累计工具错误不会被成功重置；中止隔离触及的查询。
- `reply.py` / `grounding.py`：比较回复控制、缺失成分与价格规格等有限规则核验。
- `app/safety/guard.py`：输入、候选、替换和拒答审核；不能当作通用医学判断。
- `app/analysis/review_parser.py`：独立关键词评论解析；没有注册为Agent工具，扩展目录入口仍是占位。

## 展示任务

按S001查询价格，切换S002后追问规格；明确完整名称和不明确片段分别处理；比较两个商品并更改条件；医疗拒答后回到正常查询；S999返回空结果后重选有效SKU；检查纯物流是否执行商品工具；本轮独立改写问句尚有阻断失败，不能宣称全部通过。具体输入和预期见[合成场景](demo_logs.md)。

这些任务的离线模型提议由脚本预设，本地工具和规则真实执行。真实模型是否自主做出同样选择尚未验证，不以脚本输出截图冒充真实模型效果。

## 如何复查

安装、配置、CLI启动和测试入口见[README](../README.md)。普通测试命令不具备验收沙箱的网络/写入保证；本轮隔离验收结果在README独立列出。安装依赖、真实CLI和干净环境重现仍有不同验证边界。

本项目未配置HTTP服务、UI、RAG、长期数据库、人工接管或真实电商同步。许可证和公开权需人工决定；没有生产、商业或医疗认证承诺。
